# 설치

1. **Unity Hub 설치:** Windows 11 x64용 설치 파일 실행.
2. **로그인 및 라이선스:** Unity 계정으로 로그인하고 무료 Unity Personal 활성화.
3. **Unity Editor 설치:** Hub → 설치(Installs) → 에디터 설치(Install Editor) → Unity 6.3 LTS (`6000.3.25f1`) 선택.
4. **추가 모듈 선택:** `Mac Build Support (Mono)`, 한국어 언어 팩 체크. `Microsoft Visual Studio Community`는 체크 해제.
5. **VS Code 설치:** 최신 Stable 정식 버전 설치.
6. **Unity 확장 설치:** VS Code → 확장(`Ctrl + Shift + X`) → `@id:VisualStudioToolsForUnity.vstuc` 검색 → Microsoft의 Unity 설치. C#, C# Dev Kit도 함께 설치됨.
