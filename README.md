# practice_puzzle_game

Unity 6.3 LTS `6000.3.25f1`와 C#으로 만드는 2D 매치3 퍼즐입니다. 현재 개발 버전은 **0.11.0**이며 5개 월드·50개 스테이지, 로드맵·별·메달·아이템과 로컬 진행 저장을 구현했습니다. 실제 사용자 검증과 출시 준비는 후속 작업입니다.

## 실행

1. Unity Hub에서 이 프로젝트를 엽니다.
2. `Assets/_Project/Scenes/Boot.unity`를 더블클릭합니다.
3. 위쪽 **▶ 실행**을 누르면 설정·진행도·레벨·소리 준비가 끝난 뒤 로드맵으로 넘어갑니다. 열린 스테이지를 클릭해 목표·최고 기록을 확인하고 **시작**을 누릅니다. 보드만 개발하려면 `Game.unity`를 열어 실행합니다.
4. 레벨별 seed·이동수·점수·수집·Frost 목표와 배치는 `Data/Levels/Definitions/Level_001.asset`부터 `Level_050.asset`의 Inspector에서 조정합니다. 첫 5개 레벨은 고정 초기 배치를 사용합니다.

## 조작

1. 블록을 마우스 왼쪽 버튼으로 누른 채 상하좌우로 끌고 놓으면 바로 옆 블록과 교환합니다.
2. 같은 색·모양이 3개 이상 맞으면 사라지고 위 블록과 새 블록이 빈칸을 채웁니다. 일반 매치나 특수 교환이 성립하지 않으면 교환 전 자리로 돌아옵니다.
3. 두 블록을 차례로 클릭하는 방식도 가능합니다. 같은 블록 재클릭·우클릭은 선택 취소입니다. ESC는 드래그·블록·아이템 대상 선택이 있으면 먼저 취소하고, 선택이 없으면 설정창을 엽니다.
4. 보드 밖·UI 위에서 놓거나 창 포커스를 잃으면 드래그를 취소합니다. 교환·제거·낙하 중에는 추가 입력을 받지 않습니다.
5. 이스터에그: 플레이 중 **P**를 누르면 현재 스테이지의 모든 목표를 즉시 완료합니다. 저장·다음 스테이지 해금·결과창을 처리하지만 신규 별·메달·아이템 보상은 지급하지 않습니다. 설정/다른 팝업이 열린 동안은 작동하지 않으며 키를 누른 채 다음 스테이지로 넘어가도 연속으로 완료하지 않습니다.
6. 정보 패널의 **망치·폭탄·섞기·이동 +5** 아이템을 눌러 설명을 확인합니다. 망치/폭탄은 대상 캔디를 클릭하고, 섞기/이동 +5는 사용 버튼으로 확정합니다. 대상 선택 중 Esc·우클릭·닫기는 무료 취소이며 이때 Esc는 설정을 열지 않습니다.

7. **방향키**로 보드 커서를 옮기고 **Enter**로 선택·교환합니다. **1~4**는 아이템 설명과 사용 확인을 열며, **H**는 수동 힌트, **F1**은 도움말입니다. 자동 힌트와 연출 속도는 설정의 플레이 탭에서 바꿉니다.

아이템은 각 3개로 시작하며 최대 99개까지 보관합니다. 스테이지 첫 정상 클리어마다 정해진 1종을, 매 5번째 스테이지에서는 4종을 각 1개씩 받습니다. 재도전·P 키 클리어에는 보상이 없습니다. 모든 아이템은 이동 횟수를 쓰지 않으며 완료된 사용은 재시작해도 반환되지 않습니다. 수량과 보상 수령 기록은 기존 진행도를 유지하는 v4 저장에 함께 보관합니다. [상세 규칙](docs/campaign.md).

## 50개 스테이지와 진행 저장

1. **1-1**에서는 이동 20회 안에 500점을 모읍니다. 제거한 블록 1개당 10점이며 연쇄 제거도 합산합니다.
2. 일반 매치 또는 특수 효과가 성립한 교환에만 이동수 1회를 사용합니다. 실패 교환과 자동 연쇄에는 추가로 차감하지 않습니다.
3. 정보 패널에서 현재 점수·목표 점수·남은 이동수를 확인합니다.
4. 마지막 연쇄가 끝난 뒤 점수·색상 수집·Frost 목표를 모두 달성하면 성공, 이동수가 0이고 목표 미달이면 실패합니다. 마지막 이동에서도 성공할 수 있습니다.
5. 결과창의 **다시 하기**를 누르면 같은 초기 보드와 전체 이동수로 다시 시작합니다. 정보 패널에도 다시 하기 버튼이 있으며, 진행 중 재시작·맵 이동은 확인창을 거칩니다.
6. **사탕 정원 → 오렌지 과수원 → 얼음 소다 → 포도 밤정원 → 무지개 궁전**에 각각 10개, **1-1~5-10**까지 있습니다. 후반에는 최대 3색 수집과 내구도 1~3의 Frost가 등장합니다. 월드별 이동수는 실제 자동 플레이 결과로 조정했습니다.
7. 처음에는 1-1만 열립니다. 클리어하면 다음 스테이지가 열리고 결과창에서 바로 이동할 수 있습니다. 정보 패널의 **맵 보기**로 로드맵에 돌아갑니다. 진행 중인 보드는 저장하지 않습니다.
8. 클리어 기록·최고 점수·별·메달·아이템·마지막 선택을 `Application.persistentDataPath/progress.json`에 즉시 저장합니다. 게임 배포용 `_Data` 폴더에는 저장하지 않습니다. `.bak` 복구본을 지원합니다. Editor 플레이는 개인 저장을 건드리지 않는 메모리 진행도이며, 실제 실행 파일은 재실행해도 기록이 남습니다.
9. 정상 클리어에 별 1개, 아이템 미사용에 1개, 기본 이동의 20% 이상(올림, 최소 3회)을 남기면 1개를 받습니다. 이동 +5로 추가한 횟수는 여유 이동 평가에 포함하지 않습니다. 별은 한 시도의 최고 개수, 두 메달은 각각 획득 여부를 저장합니다. v1~v3 저장을 읽으면 기록·재고를 유지하고 기존 완료 스테이지에 별 1개를 부여합니다.
10. 지도에서 별 합계·월드 진행도·다음 4종 보상 지점을 확인합니다. 잠긴 스테이지도 목표와 해금 조건을 미리 볼 수 있습니다. 결과창에는 최고 기록 갱신·목표 부족량·실제로 받은 보상 그림이 나옵니다.

초기 난이도·저장 경로·제작 방법은 [campaign.md](docs/campaign.md)를 참고합니다. 로그인·서버 동기화는 아직 없습니다.

5번 스테이지부터 사탕을 가두는 Frost가 나옵니다. 얼음 속 사탕은 해동 전까지 교환·낙하·셔플할 수 없습니다. 타격마다 얼음 내구도만 1 줄며 같은 제거 단계의 중복 효과는 한 번만 피해를 줍니다. 해동된 사탕은 다음 제거 단계부터 제거·특수 발동이 가능합니다. 첫 5개 레벨에 규칙 안내가 나오며 기본 6초 동안 조작하지 않으면 남은 목표를 고려한 교환을 추천합니다. 결과창에서 어려웠던 이유를 남기면 플레이 시간·교환 순서와 함께 기기의 `playtest.jsonl`에 기록합니다.

## 특수 블록

1. 가로 4개는 가로 크림 줄무늬 사탕을 만들어 좌우 한 줄을 지웁니다. 세로 4개는 세로 크림 줄무늬 사탕을 만들어 상하 한 줄을 지웁니다.
2. T·L·십자 매치는 주변 3×3을 지우는 봉지 사탕을 만듭니다.
3. 5개 이상 직선 매치는 무지개 소용돌이 사탕을 만듭니다. 옆 사탕과 교환하면 그 색을 지웁니다.
4. 특수 사탕은 매치나 다른 특수 효과에 닿으면 발동합니다. 방금 만들어진 사탕은 해당 제거 단계에서 살아남습니다.
5. 특수 사탕끼리 교환하면 매치가 없어도 두 효과가 발동하며, 무지개 사탕끼리 교환하면 보드 전체를 지웁니다. 한 번의 교환에 이동수는 1회만 사용합니다.
6. 특수 사탕은 기존 사탕의 반투명 재질·광택·색·모양을 참고해 새로 그린 전용 스프라이트 19종을 사용합니다.

## 사탕 테마

1. 하트·보석·물방울·쿠션·구슬·꽃 사탕 6종과 파스텔 사탕 정원 배경을 적용했습니다.
2. 넓은 창에서는 왼쪽에 정보, 오른쪽에 보드를 배치하고 좁은 창에서는 정보를 위로 옮깁니다.
3. 일반 매치의 눌림·팽창·섬광·설탕 조각, 가로/세로로 퍼지는 빛, 포장 폭발, 무지개 연결, 특수 생성·착지 탄성을 적용했습니다. 연쇄 효과는 빛이 닿는 순서로 재생합니다.
4. 스테이지 이름·맵 버튼을 분리하고 남은 이동수를 강조합니다. 첫 5개 레벨은 별 도전 안내와 아래의 규칙 안내 영역을 확보해 조작 중 보드 좌표가 움직이지 않게 합니다.
5. 수집·얼음 목표는 미완료 목표부터 사탕/얼음 그림과 진행 막대로 표시하고, 달성한 목표는 완료 표시로 간소화합니다. Frost는 입체 얼음 3종으로 내구도를 구분하며 두 칸 힌트는 사탕을 움직이지 않고 교환 방향을 알려 줍니다.
6. UI는 Jua를 사용하고 이전 제목용 Bagel Fat One도 보관합니다. Google Fonts 원본 TTF와 OFL 라이선스를 동봉합니다.
7. 성공·재도전·전체 완주에 별·하트·왕관 배지를 표시합니다. 결과창 등장·캔디 축하 입자·목표 완료 반응은 효과 감소 설정에 맞춰 생략합니다.
8. 생성 이미지·최종 프롬프트는 [generated-assets.md](docs/generated-assets.md)에 기록했습니다.

## Windows 개발 빌드

로컬 출력: `Builds/Windows/0.11.0/practice_puzzle_game.exe`

실행 파일 옆의 데이터 폴더·DLL도 함께 필요합니다. Unity에서 다시 만들려면 **Puzzle Game → Build Windows Prototype**을 사용합니다. Mac 빌드·실기기 검증은 아직 진행하지 않았습니다.

## 설정

1. 점수판 아래 **설정** 버튼 또는 선택이 없는 상태에서 **ESC**로 설정창을 엽니다. 화면/소리/플레이/도움말 탭을 한 창에서 이용하며 열려 있는 동안 보드 입력과 폭발·낙하가 일시정지됩니다.
2. 화면 탭에서 해상도를 고르고 **창모드** 스위치로 창/전체 화면을 선택한 뒤 **적용**을 누릅니다. 끄면 테두리 없는 전체 화면으로 전환합니다. 적용 중에는 닫기와 탭 전환을 잠시 막습니다.
3. **계속하기** 또는 ESC로 게임을 이어갑니다. 해상도 목록이 펼쳐져 있으면 첫 ESC는 목록만 닫습니다. 적용하지 않은 선택은 닫을 때 취소됩니다.
4. **게임 종료**는 실행 파일을 종료합니다. Unity 편집기에서는 플레이 모드를 종료합니다.
5. 적용한 화면 설정은 `Application.persistentDataPath/settings.json`에 저장하고 다음 실행에 복원합니다. 이전 정상 저장본 `.bak`으로 손상 복구를 지원합니다. 진행 중 보드는 저장하지 않습니다.
6. 소리 탭에서 음악·효과음을 0~100% 슬라이더와 음소거 스위치로 각각 조절합니다. 음소거를 해제하면 기존 음량이 유지됩니다.
7. 플레이 탭에서 자동 힌트 켜기/끄기·대기 시간 3/6/10/15초, 보드 연출 1/1.5/2배, 한국어/영어, 이펙트 감소·색상 숫자 표시를 설정합니다. 변경 즉시 저장됩니다. 수동 힌트는 자동 힌트를 꺼도 사용할 수 있습니다.
8. 도움말 탭에서 크레딧과 그림 도움말을 볼 수 있습니다. 지도에서는 **진행 초기화**를 제공하며 확인 전에는 기록이 바뀌지 않습니다. 초기화하면 백업도 새 진행으로 바꿉니다. 긴 내용은 스크롤하고 고정된 닫기 버튼, 오른쪽 위 X 또는 ESC로 닫습니다.
