# practice_puzzle_game

Unity 6.3 LTS `6000.3.25f1`와 C#으로 만드는 2D 매치3 퍼즐입니다. Windows·macOS 출시를 목표로 하며, 현재 5개 월드·50개 스테이지, 로드맵과 로컬 진행 저장을 구현했습니다.

## 실행

1. Unity Hub에서 이 프로젝트를 엽니다.
2. `Assets/_Project/Scenes/Boot.unity`를 더블클릭합니다.
3. 위쪽 **▶ 실행**을 누르면 사탕 정원 로딩 화면이 약 5초 표시된 뒤 로드맵으로 넘어갑니다. 열린 스테이지를 클릭하면 8×8 보드에 진입합니다. 보드만 개발하려면 `Game.unity`를 열어 실행합니다.
4. 레벨별 seed·이동수·점수·수집 목표는 `Data/Levels/Definitions/Level_001.asset`부터 `Level_050.asset`의 Inspector에서 조정합니다. 같은 seed는 같은 초기 보드를 만듭니다.

## 조작

1. 블록을 마우스 왼쪽 버튼으로 누른 채 상하좌우로 끌고 놓으면 바로 옆 블록과 교환합니다.
2. 같은 색·모양이 3개 이상 맞으면 사라지고 위 블록과 새 블록이 빈칸을 채웁니다. 일반 매치나 특수 교환이 성립하지 않으면 교환 전 자리로 돌아옵니다.
3. 두 블록을 차례로 클릭하는 방식도 가능합니다. 같은 블록 재클릭·우클릭은 선택 취소입니다. ESC는 진행 중인 드래그를 취소하고 설정창을 엽니다.
4. 보드 밖·UI 위에서 놓거나 창 포커스를 잃으면 드래그를 취소합니다. 교환·제거·낙하 중에는 추가 입력을 받지 않습니다.

## 50개 스테이지와 진행 저장

1. 기존 연습 스테이지는 **1-1**입니다. 이동 20회 안에 1,000점을 모읍니다. 제거한 블록 1개당 10점이며 연쇄 제거도 합산합니다.
2. 일반 매치 또는 특수 효과가 성립한 교환에만 이동수 1회를 사용합니다. 실패 교환과 자동 연쇄에는 추가로 차감하지 않습니다.
3. 정보 패널에서 현재 점수·목표 점수·남은 이동수를 확인합니다.
4. 마지막 연쇄가 끝난 뒤 점수와 색상 수집 목표를 모두 달성하면 성공, 이동수가 0이고 목표 미달이면 실패합니다. 마지막 이동에서도 성공할 수 있습니다.
5. 결과창의 **다시 하기**를 누르면 같은 초기 보드와 전체 이동수로 다시 시작합니다. 화면 아래에도 다시 하기 버튼이 있습니다.
6. **사탕 정원 → 오렌지 과수원 → 얼음 소다 → 포도 밤정원 → 무지개 궁전**에 각각 10개, **1-1~5-10**까지 있습니다. 후반으로 갈수록 점수 목표가 높아지고 이동수는 20→19→18회, 수집 목표는 최대 3색으로 늘어납니다.
7. 처음에는 1-1만 열립니다. 클리어하면 다음 스테이지가 열리고 결과창에서 바로 이동할 수 있습니다. 정보 패널의 **맵 보기**로 로드맵에 돌아갑니다. 진행 중인 보드는 저장하지 않습니다.
8. 클리어 기록·최고 점수·마지막 선택을 `Application.persistentDataPath/progress.json`에 즉시 저장합니다. 게임 배포용 `_Data` 폴더에는 저장하지 않습니다. `.bak` 복구본을 지원합니다. Editor 플레이는 개인 저장을 건드리지 않는 메모리 진행도이며, 실제 실행 파일은 재실행해도 기록이 남습니다.

초기 난이도·저장 경로·제작 방법은 [campaign.md](docs/campaign.md)를 참고합니다. 장애물·로그인·서버 동기화는 아직 없습니다.

## 특수 블록

1. 가로 4개는 가로 크림 줄무늬 사탕을 만들어 좌우 한 줄을 지웁니다. 세로 4개는 세로 크림 줄무늬 사탕을 만들어 상하 한 줄을 지웁니다.
2. T·L·십자 매치는 주변 3×3을 지우는 봉지 사탕을 만듭니다.
3. 5개 이상 직선 매치는 무지개 소용돌이 사탕을 만듭니다. 옆 사탕과 교환하면 그 색을 지웁니다.
4. 특수 사탕은 매치나 다른 특수 효과에 닿으면 발동합니다. 방금 만들어진 사탕은 해당 제거 단계에서 살아남습니다.
5. 특수 사탕끼리 교환하면 매치가 없어도 두 효과가 발동하며, 무지개 사탕끼리 교환하면 보드 전체를 지웁니다. 한 번의 교환에 이동수는 1회만 사용합니다.
6. 특수 사탕은 기존 사탕의 반투명 재질·광택·색·모양을 참고해 새로 그린 전용 스프라이트 19종을 사용합니다.

## 사탕 테마

1. 하트·보석·물방울·쿠션·구슬·꽃 사탕 6종과 파스텔 사탕 정원 배경을 적용했습니다.
2. 넓은 창에서는 왼쪽에 정보, 오른쪽에 보드를 배치하고 좁은 창에서는 정보를 위로 옮깁니다.
3. 일반 매치의 눌림·팽창·섬광·설탕 조각, 가로/세로로 퍼지는 빛, 포장 폭발, 무지개 연결, 특수 생성·착지 탄성을 적용했습니다. 연쇄 효과는 빛이 닿는 순서로 재생합니다.
4. 안내 문구를 없애 보드를 확대했습니다. SUGAR GARDEN·스테이지 이름은 점수판 안에 있으며 가로 화면에서 점수판의 위아래 끝을 보드 프레임과 맞춥니다.
5. 한글 게임 제목을 없애고 **SUGAR GARDEN**을 크게 표시했습니다. 점수판 하단에 아이템용 빈 슬롯 4개를 배치했으며 기능은 추후 연결합니다.
6. 영문 제목·점수·버튼·설명은 Jua, 결과창 제목은 Bagel Fat One을 사용합니다. Google Fonts의 원본 TTF와 OFL 라이선스를 보관합니다.
7. 생성 이미지·최종 프롬프트는 [generated-assets.md](docs/generated-assets.md)에 기록했습니다.

## Windows 개발 빌드

로컬 출력: `Builds/Windows/0.9.4/practice_puzzle_game.exe`

실행 파일 옆의 데이터 폴더·DLL도 함께 필요합니다. Unity에서 다시 만들려면 **Puzzle Game → Build Windows Prototype**을 사용합니다. Mac 빌드·실기기 검증은 아직 진행하지 않았습니다.

## 설정

1. 점수판 아래 **설정** 버튼 또는 **ESC**로 설정창을 엽니다. 열려 있는 동안 보드 입력과 폭발·낙하가 일시정지됩니다.
2. 해상도를 고르고 **창모드** 체크박스로 창/전체 화면을 선택한 뒤 **적용**을 누릅니다. 체크 해제 시 테두리 없는 전체 화면으로 전환합니다.
3. **계속하기** 또는 ESC로 게임을 이어갑니다. 해상도 목록이 펼쳐져 있으면 첫 ESC는 목록만 닫습니다. 적용하지 않은 선택은 닫을 때 취소됩니다.
4. **게임 종료**는 실행 파일을 종료합니다. Unity 편집기에서는 플레이 모드를 종료합니다.
5. 적용한 화면 설정은 `Application.persistentDataPath/settings.json`에 저장하고 다음 실행에 복원합니다. 이전 정상 저장본 `.bak`으로 손상 복구를 지원합니다. 진행 중 보드는 저장하지 않습니다.
